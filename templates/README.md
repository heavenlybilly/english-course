# Шаблоны уроков

Шаблоны помогают сохранять понятную структуру, но не являются обязательной формой каждого занятия.

Обычный крупный урок использует:

- [01-lesson.md](01-lesson.md) — основной материал;
- [02-practice.md](02-practice.md) — дополнительная практика;
- [03-answers.md](03-answers.md) — ответы и модели.

Короткий или специальный урок может состоять из одного или двух файлов, если ответы не раскрывают следующие задания раньше времени.

## Как использовать

1. Возьми номер и название из [Course Map](../COURSE-MAP.md).
2. Выбери подходящую последовательность из [типов уроков](lesson-types.md).
3. Оставь только полезные разделы и замени подсказки в фигурных скобках.
4. Используй простую сквозную нумерацию `Задание 1`, `Задание 2` и далее. Продолжи её в `02-practice.md`, затем повтори номера, названия и порядок пунктов в `03-answers.md`.
5. Проверь, что старый материал действительно возвращается, а все закрытые задания имеют ответы.

## Визуальная структура

- `##` — крупный раздел урока с понятным содержательным названием;
- `###` — отдельное пронумерованное задание;
- `####` — конкретный тип учебного материала: `Диалог`, `Короткий текст`, `Примеры`, `Полезные выражения`, `Грамматическая модель`, `Аудио` и так далее.

Не используй общий заголовок `Материал`. По заголовку должно быть понятно, что именно находится ниже. В готовом уроке не должно быть технических кодов вроде `2A-1`.

В готовом уроке также не должно быть YAML, глобальных ID, оценок времени или редакторских комментариев.

По умолчанию используй современный американский английский. Кратко отмечай британский вариант только при распространённом или учебно важном различии; не дублируй пометки вариантов возле каждого примера. Аутентичный материал сохраняет исходный вариант.

Для обычной новой конструкции ориентир — 15+ разнообразных примеров, для центральной темы — 20–30+. Основной грамматической теме обычно требуется значительный набор упражнений разных типов. Активная лексика: примерно 5–8 единиц в обычном уроке и 8–15 в лексическом.
