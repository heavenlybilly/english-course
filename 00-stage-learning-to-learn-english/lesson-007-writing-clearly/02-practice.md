# Lesson 007 — Additional Practice

[Lesson](01-lesson.md) · [Answers](03-answers.md)

**Additional practice.**

## Clearer Language

### Task 8. Describe It More Clearly

1. Describe a kettle without naming it.
2. Describe a neighbor without using *neighbor*.
3. Rewrite “I am dissatisfied with my accommodation” in simple English.
4. Improve “Please bring that thing tomorrow” by inventing a plausible object, description and purpose.
5. Correct and simplify: “I have an unliking job.”
6. Your reader misunderstood “the thing for the door.” Add enough detail to distinguish a key from a door handle.

## Delayed Writing

### Task 9. Write from Memory

Return to this task after studying other material. Write 60–100 words to a friend about a skill you want to learn. Explain a difficulty and ask for advice. First write without a model. Then check your message and keep both versions.

## Challenge

### Task 10. Ask a Shop for Help

Write a 70–100 word message to a shop about an item you bought. You cannot recall its exact name. Include what it does, one identifying detail, the problem and the help you want. You may invent purchase details for this exercise.
