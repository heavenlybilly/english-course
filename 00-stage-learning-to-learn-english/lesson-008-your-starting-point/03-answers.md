## Task 4. Make Vocabulary Decisions

1. **Guess** or **check later**. Exact understanding is unnecessary for the main idea.
2. **Look up now.** The tool and its function control the requested detail.
3. **Look up now** before productive use. A guess should be confirmed.
4. **Ignore** for now. The available context is sufficient for the purpose.

The purpose can change the best decision.

## Task 11. Write a Request for Guidance

Check for all five content requirements and the self-check. A different structure is acceptable if the reader can understand and answer the request.

**Possible response**

> Hi Maya, I'd like to learn how to repair simple wooden furniture. I found an old chair that I want to use at home, but one leg moves when I sit down. I cleaned the chair and checked the screws, but that did not solve the problem. Could you show me how to find where the leg is loose? I may also need the tool that holds two pieces together while glue dries. Should I buy one, or could I borrow yours for the weekend?

The model states a clear goal, gives concrete evidence, describes **clamp** when the exact word is unavailable and ends with questions that can receive specific answers.

## Task 12. Explain What You Want to Learn

## Task 13. Choose Evidence, Not a Score

There is no universal answer. Use task evidence:

- **secure for now:** you completed the relevant task independently and can explain the method;
- **review first:** you depended on the answer key, transcript or earlier lesson before the task allowed it, or the result remained unclear;
- **not enough evidence:** you did not attempt the task or the source was unavailable.

Connect every **review first** decision to the matching route in `02-practice.md`.

> **Unit:** repair something
